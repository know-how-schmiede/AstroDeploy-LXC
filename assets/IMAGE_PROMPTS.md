# Bildgenerierung

Erstellt am 30.10.2026 mit dem integrierten Bildgenerierungswerkzeug.
Beide Dateien sind Rastergrafiken im PNG-Format; das Logo besitzt einen
transparenten Hintergrund. Das Banner verwendet das Logo als Bildreferenz.

## Logo – assets/logo.png

Use case: logo-brand. Create a polished standalone square logo icon for the open-source project AstroDeploy-LXC, a tool for deploying Astro SSR websites into Linux containers. Original symbol: a geometric rocket pointing upward integrated with three precise stacked container outlines, compact strong silhouette. Violet and electric cyan with a tiny warm orange thrust accent. Flat vector-like premium developer-tool identity, crisp edges, restrained shapes, readable small. No typography, no text, no existing Astro or Proxmox logo, no mockup, no border. Genuine transparent background. Centered with comfortable margins.
